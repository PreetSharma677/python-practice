# Python Practice

Small Python programs I wrote while learning Python.

## Programs
- `guess_game.py` - number guessing game
- `guess_game_v2.py` - improved version of the guessing game
- `rock_paper_scissors.py` - rock paper scissors against the computer
- `result_checker.py` - checks results
- `file_organizer.py` - sorts files into folders

## How to run
1. Install Python 3
2. Download or clone this repo
3. Run any program, for example:

   python guess_game.py

## What I'm learning
Loops, conditions, functions, and working with files.
